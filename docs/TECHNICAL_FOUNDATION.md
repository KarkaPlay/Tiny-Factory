# M02 — техническая основа

Статус: повторная техническая проверка после импорта рекламных wrappers пройдена в Unity 6000.3.9f1 через Unity MCP, 2026-10-05. Android APK с текущей композицией собран (code 4), но установка/запуск на физическом устройстве отложены по D12. Gameplay, ad display/callbacks и Android gameplay analytics остаются вне M02.

## Минимальные технические решения

- UI: uGUI (`com.unity.ugui` 2.0.0) — имеющийся Unity-native стек без новой зависимости. Input System 1.18.0 уже присутствует; для будущего UI выбрать один путь UI input. Reflection MCP подтвердил `TMPro.TMP_Text` в загруженной сборке `Unity.TextMeshPro`; пакет и ресурсы фактически установлены. M02 не создаёт HUD. Для M03/M06: Safe Area root, portrait previews 16:9/19.5:9/20:9, явные locked/affordable/max/loading/error состояния. Реальную читаемость и размеры touch targets оценивать на устройстве, не приписывать им значения dp без device evidence.
- Save baseline: локальный JSON в `Application.persistentDataPath`, versioned плоский DTO через Unity `JsonUtility`, без dictionary и cloud sync. План записи M05: temp → перечитать/проверить → primary и одна проверенная backup; повреждённый primary восстанавливать из backup, при двух повреждённых файлах — безопасный fresh state с сообщением; более новую schema не перезаписывать. Это решение, не реализованный код и не проверка crash safety. File move/replace атомарность на всех targets не обещается; транзакцию и восстановление проверить в M05. Clean install означает свежее состояние; сохранение после uninstall не обещается.
- PluginYG2 storage не выбран: D11 требует локальный прогресс без cloud. Встроенный PlayerPrefs fallback из vendor platform docs не доказывает требуемую versioning/backup/recovery семантику. Storage/Saves module не импортирован.
