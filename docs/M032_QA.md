# M03-R02 — Android pink rendering / 0.3.2

Статус: **hotfix0.3.2/code8 принят для Editor/build проверки; device rendering остаётся pending rerun**. Проверка Producer последовательно в роли QA: независимый QA subagent не смог запуститься (model capacity). Unity MCP выполняет единственный Engineer.

## Воспроизведение

APK 0.3.1/code7 → запуск на Realme RMX3834, Android 15 → все 3D объекты розовые, UI отображается. **FAIL, user reported**. Device log/screenshot агенту не предоставлены. Другие устройства не проверены.

## Диагностика Engineer через MCP

Temporary primitive в Editor получил sharedMaterial `Lit` / shader `Universal Render Pipeline/Lit`; shader доступен и поддерживается в Editor. FactoryPresentation.MakePrimitive использовал только GameObject.CreatePrimitive и MaterialPropertyBlock, без назначения собственного material. Material/Shader assets под Assets/TinyFactory не обнаружены. В FactoryPresentation Shader.Find отсутствует. Это подтверждает отсутствие явной material dependency в игровом коде, но фактическое состояние shader на телефоне без Player log не установлено. Hotfix должен явно включить материал/шейдер в Player и назначить его всем runtime primitives.

## Источники проверки

[Unity: выбор активного Render Pipeline](https://docs.unity.com/en-us/engine/6000.0/manual/render-pipelines/choose-a-render-pipeline/srp-setting-render-pipeline-asset) — quality override имеет приоритет над default asset. Отсутствие default asset само по себе не доказывает причину дефекта.

[Unity: Shader.Find](https://docs.unity.cn/6000.7/Documentation/ScriptReference/Shader.Find.html) — доступность shader в Editor не гарантирует его включение в Player; материал/asset dependency должен быть проверен для runtime-created объектов. Эта статья — общий критерий, не утверждение о вызове Shader.Find в текущем FactoryPresentation.

Producer read-only code review: загрузка FactoryWorldMaterial один раз в Start, назначение sharedMaterial в общем MakePrimitive для мира и items, сохранение MaterialPropertyBlock цветов. Missing asset даёт явный LogError и отключает соответствующий renderer. Нет Shader.Find runtime fallback. Gameplay runtime/balance в hotfix не менялись. Проектный material asset содержит shader reference; `.meta` сохранён. Graphics/Quality settings не менялись; URPProjectSettings получил служебный folder path при material import.

Verdict: **PASS scope/code/dependency/Editor/build; NOT RUN0.3.2 on Realme**. 0.3.1 device FAIL сохраняется как известный дефект до подтверждения результата hotfix. Установить новый APK поверх0.3.1 → проверить цвета куста, станков, стола → собрать лист → дождаться упаковки/продажи → проверить UI. Если розовый цвет сохраняется, нужны Player logs/graphics API сведения; не делать бездоказательное отключение stripping/смену pipeline.
